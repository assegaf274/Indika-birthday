README - Paket Website Ulang Tahun Indika Oktafiani

Isi paket ini (/indika_birthday_site):
- index.html            -> buka file ini di browser untuk melihat website
- music.mp3             -> musik latar (SZA - Good Days) - sudah termasuk
- foto1.jpg, foto2.jpg  -> tempat untuk meletakkan foto Indika (silakan ganti)

Cara pakai cepat:
1. Download file ZIP yang disediakan (link di akhir).
2. Ekstrak semuanya ke satu folder di laptop atau HP.
3. Masukkan dua foto Indika ke folder tersebut dan beri nama: foto1.jpg dan foto2.jpg (format JPG/PNG).
4. Buka index.html di browser (double-click). Jika musik tidak otomatis, klik tombol "Putar Musik".

Catatan:
- Jika kamu mau mengganti teks ucapan, edit bagian <div class='message'> di index.html.
- Untuk mengubah warna tema, cari :root CSS di atas dan ubah variabelnya.
- Bila mau saya bantu meng-hosting (GitHub Pages atau Netlify), bilang saja.

Selamat merayakan! 🎉
